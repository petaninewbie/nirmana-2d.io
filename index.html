1. Pemahaman Konsep: 3 Elemen Dasar Dwimatra

Sebelum mulai berkarya secara digital, pahami bagaimana tiga elemen ini bekerja membentuk sebuah desain:

Titik (Point): Elemen visual paling sederhana. Titik menjadi pusat perhatian (focal point) dan awal dari semua bentuk. Dalam jumlah banyak dan kerapatan berbeda, kumpulan titik dapat menciptakan ritme atau bayangan.

Garis (Line): Jejak dari gerakan titik. Garis berfungsi memberikan arah, pembatas, struktur, serta menyampaikan kesan psikologis tertentu (misal: garis tegas, dinamis, atau tenang).

Bidang (Plane): Area tertutup dua dimensi yang dibentuk oleh garis yang saling bertemu. Bentuk dasar bidang meliputi geometri seperti lingkaran, persegi, dan segitiga.

2. Panduan Cepat Navigasi Menu Shapes

Pilih salah satu aplikasi yang ingin kamu gunakan (Canva atau Figma):

A. Penggunaan di Canva

  1. Buka Canva dan buat desain baru ukuran 1080 x 1080 px (Square/Post Instagram).
  2. Pilih menu Elemen (Elements) di panel sebelah kiri.
  3. Cari bagian Garis & Bentuk (Lines & Shapes).
  4. Shortcut Cepat:
    • Tekan huruf C di keyboard untuk memunculkan Lingkaran (Circle).
    • Tekan huruf R untuk memunculkan Persegi (Rectangle).
    • Tekan huruf L untuk memunculkan Garis (Line).

B. Penggunaan di Figma

  1. Buka Figma dan buat Frame baru (F) berukuran 1080 x 1080 px.
  2. Akses menu Shape Tools di toolbar atas (ikon Persegi).
  3. Shortcut Cepat:
    • R : Rectangle (Bidang/Persegi)
    • O : Ellipse (Bidang Lingkaran / Titik)
    • L : Line (Garis)
    • P : Pen Tool (Untuk membuat garis atau bidang kustom)

3. Aktivitas Siswa: "Kanvas Eksplorasi 2D"

Instruksi Tugas: Buat sebuah komposisi visual Nirmana 2D non-representasional (abstrak) yang menggabungkan elemen titik, garis, dan bidang pada satu kanvas digital.

Aturan Main Aktivitas:

  1. Tanpa Tekstur & Gambar: Gunakan warna solid/flat (flat color). Dilarang menggunakan foto, tekstur, atau efek gradasi yang kompleks.
  2. Eksplorasi Skala & Posisi: Mainkan variasi ukuran (besar-kecil), rotasi, kerapatan, serta penataan (layout) elemen visual.
  3. Jumlah Halaman: Buat 2 variasi komposisi berbeda di dalam satu file proyek/kanvas:
    • Variasi 1: Fokus pada irama dan pengulangan (repetition/pattern).
    • Variasi 2: Fokus pada kontras dan pusat perhatian (focal point).

4. Format Pengumpulan Karya (Bukti Karya Siswa)

Kumpulkan file tugasmu dalam bentuk:

  • Format File: PNG/PDF kualitas tinggi atau lampirkan Link Share (dengan akses melihat/view) dari Canva atau Figma milikmu.
  • Penamaan File: DesainGrafis_Nirmana2D_NamaSiswa_Kelas.pdf

2 Contoh Langkah-demi-Langkah Pengerjaan Nirmana 2D untuk Pemula

Berikut adalah instruksi pengerjaan detail untuk siswa yang baru pertama kali menggunakan software Canva atau Figma:

PILIHAN A: Langkah Pengerjaan di CANVA

Langkah 1: Menyiapkan Kanvas Kerja

  1. Buka canva.com dan login.
  2. Klik tombol Buat Desain (Create a design) di pojok kanan atas.
  3. Pilih Ukuran Khusus (Custom size), ketik 1080 x 1080 piksel, lalu klik Buat Desain Baru.
  4. Biarkan latar belakang (background) berwarna putih polos.

Langkah 2: Membuat Elemen Titik

  1. Tekan tombol huruf C di keyboard untuk memunculkan bentuk Lingkaran.
  2. Perkecil ukuran lingkaran tersebut hingga berukuran sangat kecil menyerupai titik.
  3. Beri warna hitam pada titik tersebut.
  4. Duplikat titik dengan menekan tombol Ctrl + D (atau Cmd + D di Mac) berulang kali.
  5. Susun kumpulan titik tersebut hingga membentuk irama (misalnya: dari titik yang rapat secara bertahap menjadi renggang).

Langkah 3: Membuat Elemen Garis

  1. Tekan tombol huruf L di keyboard untuk memunculkan Garis.
  2. Klik pada garis tersebut, lalu lihat barisan menu di bagian atas:
    • Atur ketebalan garis pada opsi Model Garis / Ketebalan Garis.
    • Ubah warna garis menjadi hitam atau abu-abu tua.
  3. Buat beberapa garis dengan ketebalan yang bervariasi (ada yang tebal, sedang, dan tipis) serta arah yang berbeda (horisontal, vertikal, atau diagonal).

Langkah 4: Membuat Elemen Bidang

  1. Tekan tombol huruf R untuk memunculkan Persegi/Bidang.
  2. Atau masuk ke menu Elemen > Garis & Bentuk untuk memilih segitiga atau bentuk geometri lainnya.
  3. Ubah skala/ukuran bidang (buat ada yang berukuran besar sebagai pusat perhatian, dan sedang/kecil sebagai penyeimbang).

Langkah 5: Mengatur Komposisi Nirmana (Eksplorasi Layout)

  1. Miringkan atau putar (rotate) beberapa bentuk dengan menarik ikon putar di bawah elemen.
  2. Atur urutan tumpukan objek: Klik kanan pada bentuk > Posisi (Position) > pilih Maju (Bring Forward) atau Mundur (Send Backward) jika ingin menumpuk elemen.
  3. Pastikan komposisi terlihat seimbang (balanced), tidak menumpuk hanya di satu pojok.

Langkah 6: Menyimpan & Mengunduh Karya

  1. Klik tombol Bagikan (Share) di pojok kanan atas.
  2. Pilih Unduh (Download).
  3. Pilih Jenis File: PNG atau PDF Standard.
  4. Klik Unduh.

PILIHAN B: Langkah Pengerjaan di FIGMA

Langkah 1: Membuat Frame / Kanvas

  1. Buka figma.com dan buat Design File baru.
  2. Tekan tombol F pada keyboard, lalu klik dan tahan (drag) di area kerja hingga membentuk persegi, atau pilih preset Instagram Post (1080 x 1080) di panel kanan.
  3. Beri nama Frame kamu: Nirmana_NamaSiswa.

Langkah 2: Membuat Elemen Titik

  1. Tekan tombol O untuk memilih alat Ellipse (Lingkaran).
  2. Tahan tombol Shift sambil drag kursor agar lingkarannya bulat sempurna.
  3. Buat ukurannya kecil (misal: 8x8 piksel) hingga menjadi titik.
  4. Di panel kanan pada bagian Fill, ubah warnanya menjadi hitam solid (#000000).
  5. Duplikat titik dengan menekan Ctrl + D (atau Cmd + D di Mac) lalu sebar untuk membentuk pola titik.

Langkah 3: Membuat Elemen Garis

  1. Tekan tombol L untuk memilih alat Line.
  2. Tahan tombol Shift saat menarik garis agar lurus presisi (0°, 45°, atau 90°).
  3. Di panel kanan pada bagian Stroke, ubah ketebalan garis (misal: 2px, 5px, atau 10px).

Langkah 4: Membuat Elemen Bidang

  1. Tekan tombol R untuk membuat Rectangle (Persegi) atau klik tanda panah di sebelah ikon shape di toolbar atas untuk memilih Polygon (Segitiga/Bintang).
  2. Tentukan ukuran bidang besar dan kecil.
  3. Atur warna pada bagian Fill (gunakan warna hitam, putih dengan stroke tebal, atau variasi warna abu-abu solid).

Langkah 5: Mengatur Komposisi & Struktur Layer

  1. Memutar bentuk: Arahkan kursor ke dekat sudut luar bentuk hingga kursor berubah menjadi ikon panah melengkung, lalu putar.
  2. Mengatur susunan tumpukan (Layer):
    • Tekan [ untuk memindahkan objek ke belakang.
    • Tekan ] untuk memindahkan objek ke depan.
  3. Kelompokkan (Group) bentuk jika diperlukan dengan memblok elemen-elemen tersebut lalu tekan Ctrl + G.

Langkah 6: Meng-ekspor Karya

  1. Klik pada nama Frame kamu di kanvas.
  2. Lihat panel kanan paling bawah, cari bagian Export.
  3. Pilih format PNG atau PDF, lalu klik tombol Export [Nama Frame].

💡 Tips Penting Pemula saat Mengarang Nirmana 2D:

  • Jaga Prinsip Monokrom/Flat: Agar fokus pada bentuk dasar (geometri), gunakan variasi warna terbatas seperti hitam, putih, dan tingkatan abu-abu (grayscale).
  • Eksplorasi Kontras: Sandingkan elemen yang sangat besar dengan elemen yang sangat kecil untuk menciptakan fokus utama (focal point).
  • Coba Berbagai Jarak: Dekatkan beberapa titik/garis hingga terasa padat, dan renggangkan di bagian lain untuk memberikan "ruang bernapas" (white space) pada desain.

1. Standar Operasional Praktikum (SOP)

Sebelum memulai praktik di lab komputer atau perangkat mandiri, pastikan:

  1. Perangkat terhubung ke koneksi internet yang stabil.
  2. Resolusi kanvas utama diatur tepat pada 1080 x 1080 px (skala 1:1).
  3. Mode warna fokus pada penggunaan warna solid (Flat Color/Monochrome) untuk melatih kepekaan bentuk (form) sebelum masuk ke materi warna lanjutan.

2. Panduan Eksekusi Navigasi Tools Shapes

A. Penguasaan Fitur di CANVA

[ Menu Elemen ] ───> [ Garis & Bentuk ] ───> [ Pilihan Geometri ]

Operasi Objek Utama:

  • Shortcut Cepat: Tekan C (Circle), R (Rectangle), L (Line).
  • Pengaturan Skala Presisi: Tahan tombol Shift saat menggeser sudut objek agar proporsi lebar dan tinggi tetap seimbang.
  • Hierarki Layer: Klik kanan objek → Posisi (Position) → Pilih Maju (Bring Forward) atau Mundur (Send Backward).
  • Duplikasi Cepat: Pilih objek → Tekan Ctrl + D (Cmd + D di Mac).

B. Penguasaan Fitur di FIGMA

[ Top Toolbar ] ───> [ Shape Tools ] ───> [ Rectangle / Ellipse / Line / Polygon ]

Operasi Objek Utama:

  • Shortcut Cepat: Tekan R (Rectangle), O (Ellipse), L (Line).
  • Mengatur Tebal Garis (Stroke): Atur angka pada panel kanan bagian Stroke (misal: 2px untuk garis halus, 12px untuk garis tebal).
  • Hierarki Layer:
    • Tekan [ untuk memindahkan layer ke bawah.
    • Tekan ] untuk memindahkan layer ke atas.
  • Mengelompokkan Objek: Blok beberapa elemen → Tekan Ctrl + G (Cmd + G di Mac).

3. Skenario Latihan Langkah-demi-Langkah

Skenario 1: Membangun Komposisi Irama (Halaman 1)

  1. Titik: Buat 1 lingkaran kecil berukuran 10x10 px. Duplikat menjadi 10-15 titik. Susun membentuk alur melengkung atau gelombang dari kerapatan rapat ke renggang.
  2. Garis: Buat 3 garis sejajar dengan ketebalan berbeda (misal: 2px, 6px, 12px) yang memotong alur titik untuk menciptakan arah gerakan (directional flow).
  3. Bidang: Tambahkan 2 bidang persegi atau segitiga berukuran sedang di latar belakang untuk mengikat kelompok titik dan garis tersebut.

Skenario 2: Membangun Pusat Perhatian / Focal Point (Halaman 2)

  1. Bidang Utama: Buat 1 bidang dominan berukuran besar di area off-center (agak ke kiri atau kanan atas, gunakan prinsip rule of thirds).
  2. Kontras Titik & Garis: Lingkupi bidang utama tersebut dengan sekumpulan titik kecil atau garis-garis tipis terpancar.
  3. Penyeimbang: Letakkan 1 elemen bidang sangat kecil di area sudut berlawanan sebagai penyeimbang bobot visual (visual weight balance).
